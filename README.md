hey, I'm kibi.

I build things for the internet that nobody asked for, and then somehow people end up using them.
a day job pays the rent, the evenings go into the stuff below. the plan is to do this full time one day.


### currently messing with

**[snappie](https://github.com/licentiapoetica/snappie)**: screenshots and screen recording for KDE Plasma 6 on wayland.
basically ShareX for people who left windows. grab a screen, a window or just a piece of one
(a terminal pane, a browser tab), draw arrows on it, upload, link's in your clipboard.

**[mumh5](https://github.com/licentiapoetica/mumh5)**: a mumble client that doesn't look like it's from 2009.
chat, pictures, files up to 2 GB, screen sharing, 100 color schemes (yes, windows 95 is one of them).
works with any mumble server as it is, nothing to install on the server side.

**[f0ckm](https://github.com/licentiapoetica/frust)**: the imageboard you host yourself. tags, search, filters,
and a `config.yaml` that lets you turn most things on or off. it was node for years, now it's rust.

**[vvoid](https://github.com/licentiapoetica/vvoid)**: a hub for the browser that starts where the blue fog of the ps2 menu ends.
an endless grid of rooms that get dreamt up the first time anyone walks near them, and then stay that way for everyone after.
there's also something out there that notices you. runs in VR headsets too.

**[xyrrhak](https://github.com/licentiapoetica/xyrrhak)**: a small video site written entirely in a language i made up (520 words so far).
the server was rust until i decided rust is for cowards. now it's x86-64 assembly.
